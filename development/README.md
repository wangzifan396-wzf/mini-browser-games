# 可玩测试版

这里不是正式评级目录。开发中的玩法先验证完整循环与操作，再依据真实试玩决定是否进入主目录；不用于增加游戏数量或承诺商业品质。

## 回声禁区

[在线测试版](https://wangzifan396-wzf.github.io/mini-browser-games/development/echo-expedition.html) · [单文件源码](echo-expedition.html)

回合式离线 PvE 潜入撤离。玩家先选区域与出发装备，在种子废墟中读取守卫的下回合意图，选择潜行、搜刮、射击、EMP 或推撞；带得越多移动越慢。可以提前从入口返回，也可以冒险前往远端接应取得额外收益。行动失败丢失本次物资，基地研究保留。没有固定关卡答案，没有联网或付费服务依赖。

2026-10-05 更新加入可选的“重启灯塔”行动链。先带回两处信标的测绘记录，再任选黑匣子/电源支线，完成两者后才能启动最终广播。档案要跨回合解密并实际放在背包里撤离；电源操作改变本局电网；广播需保持在发射站附近两个敌方结算，再从远端撤离。任务进度由带回的现场证明决定，不由刷取货币决定。首次专项奖金只付一次，重复行动仍可练习并领取较低奖金。

新守卫不仅换外观：无人机移动较快、攻击单格；哨炮固定在原地封锁射界；重装守卫减轻枪击、未停机时推撞不会位移。预告、减伤后的结算预览与实际伤害读取同一规则。完成黑匣子任务解锁扫描，完成电源任务给后续计划行动增加封锁缓冲；不是只有永久生命数值提升。

- 桌面：WASD / 方向键移动，Shift 疾跑，空格结束回合；E 搜刮，C 掩护，Q EMP，R 治疗，F 撤离，T 接入站点，V 扫描，Esc 暂停。
- 手机：地图下方方向键、步行/疾跑、搜刮、结束回合、撤离；更多战术操作在侧栏。地图红叉是实际攻击范围，不是装饰。
- 存档：浏览器自动保存，菜单可导出 JSON、下载备份或确认导入。迁移浏览器/路径前请备份；本地存储并非云存档。
- 边界：当前是测试版。长期目标、区域经济与敌人变化仍需真实玩家反馈；没有异地联机，也不是 Steam 正式版。[灯塔 SDD](../docs/echo-campaign-sdd.md) · [规则与操作 QA](../docs/browser-games-refresh-qa.md)。旧自由搜刮 v1 行动继续按原规则回放，新计划行动明确记录其规则版本。

所有美术由原生 Canvas/CSS 绘制，程序音效不依赖外部素材。设计研究只借鉴决策结构，没有引入其他游戏的代码、商标角色或地图资产。
