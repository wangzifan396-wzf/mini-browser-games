## 回声禁区

[在线测试版](https://wangzifan396-wzf.github.io/mini-browser-games/development/echo-expedition.html) · [单文件源码](echo-expedition.html)

回合式离线 PvE 潜入撤离。玩家先选区域与出发装备，在种子废墟中读取守卫的下回合意图，选择潜行、搜刮、射击、EMP 或推撞；带得越多移动越慢。可以提前从入口返回，也可以冒险前往远端接应取得额外收益。行动失败丢失本次物资，基地研究保留。没有固定关卡答案，没有联网或付费服务依赖。

- 桌面：WASD / 方向键移动，Shift 疾跑，空格结束回合；E 搜刮，C 掩护，Q EMP，R 治疗，F 撤离，Esc 暂停。
- 手机：地图下方方向键、步行/疾跑、搜刮、结束回合、撤离；更多战术操作在侧栏。地图红叉是实际攻击范围，不是装饰。
- 存档：浏览器自动保存，菜单可导出 JSON、下载备份或确认导入。迁移浏览器/路径前请备份；本地存储并非云存档。
- 边界：当前是测试版。长期目标、区域经济与敌人变化仍需打磨；没有异地联机，也不是 Steam 正式版。规则和自动化测试见 [QA](../docs/browser-games-refresh-qa.md)。

所有美术由原生 Canvas/CSS 绘制，程序音效不依赖外部素材。设计研究只借鉴决策结构，没有引入其他游戏的代码、商标角色或地图资产。
