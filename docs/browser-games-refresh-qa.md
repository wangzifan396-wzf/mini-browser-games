首次记录：2026-10-04；追加验收：2026-10-05。本报告只覆盖列明文件，**不是 124 款全部重新验收，也不是 Steam 上市认证**。星团大作战、封装程序及用户未提交的文章/宣传片改动不在本批范围。

## 2026-10-05 · 重启灯塔与旧作规则复核

本轮继续深化一款新作，不以复制更多游戏提高数量。《回声禁区》仍为可玩测试版；首页增加独立入口，不混入 115 款活跃游戏或评级。四种行动使用同一规则内核，但目标不是同一搜集关卡的换名：双信标定位、跨回合解密并携带实物黑匣子、断电关闭现场电击、双天线接入后守点传输并远端撤离。前置证明只能实际带回；钱不能购买通关，重复专项奖金降至四分之一。

环境：Windows、Node v24.18.0、独立 headless Edge；桌面 1440×950、触屏布局 390×844。未占用用户前台。

- 同源规则 **157/157 通过**：旧作修复 58、开放工区 24、原自由搜刮 33、新行动链 27、历史存档 15。测试执行发布 HTML 的真实函数，边界用例中存在显式夹具，不把这些夹具当成正常资源的通关证据。
- 新行动链生成检查覆盖 **240 张地图**。从正常起始资源执行的完整计划 **24/24 完成**，共 97 次部署、1,642 个敌方回合；另有 32 次部署、5,512 次随机决策检查约束。策略读取完整地图，**不能证明普通玩家难度、乐趣或最佳平衡**。
- 历史兼容样本取自已经发布的 `905d0f4`：15 份三区、三装备与不同回合的 v1 存档。新版恢复后的完整状态 SHA-256 和再次序列化均与旧版一致，而不是用新版重新造样本。战役初始揭图及后续视线采用明确的 rules=2，原自由搜刮保持旧规则。
- 后台页面回归 **16/16 通过**；另有桌面/触屏各一条**完整四任务 UI 链，共 2/2 通过**。正常零进度基地、默认装备、真实移动/画布选择/按钮交互完成撤离，没有注入生命、金钱或任务证明。完整链还覆盖实际存盘—重载—恢复、前置解锁、黑匣子跨回合破解、扫描消耗、电源关闭、两阶段守点、远端撤离和回到自由搜刮。完成计划后真实导入旧零进度基地，选中任务自动回退可玩的信标任务；再导入从实际破解过程导出的行动，菜单和续局恢复对应的档案任务。
- 所述 18 条页面练习脚本/控制台错误 0、横向溢出 0；完整行动链运行时外部 HTTP(S) 资源请求 0。桌面完整地图、手机地图/方向键/结束回合、目标按钮和新敌人画面用截图检查，不只检查首页。模拟手机不等于真机验收。
- 旧合同、HTTP 目录和评级专项再次通过：12 个合同参考蓝图三星，124 个根目录游戏仍为 115 活跃 / 9 历史废案；目录 JSON 和 README 一致。

本轮发现并修复：

- 点击目标原先会顺便走进去，花掉 AP 导致不能接入；现在对象点击仅检查，空白相邻地面才移动。桌面地图也限制到可用视口，避免操作按钮和地图两端来回滚动。
- 守卫离开视野后，已经锁定玩家格子的攻击提示会消失；现在显示可见格子的已宣告红叉，但不泄露隐藏守卫位置。伤害预告与实际结算共享掩体、镀层、电击和多重攻击规则。
- 扫描原先说明 9 格却仍只揭示 6 格；现在可揭示第 7–9 格，不穿墙、不延长射击范围，有消耗和到期回归。陈旧的远处箱子选择不再阻止附近正常搜刮。
- 菜单导入较早基地后，不再留下一个仍选中却不能出发的已锁任务；导入有效进行中计划会同步对应任务和区域。
- 自走棋攻速改为真实动作频率，不再变相加单次伤害；移动不积攒爆发，眩晕冻结动作进度，持续加速封顶。黄金票兑现每轮一次手动免费刷新；对手预览拒绝重叠位置/UID，合成优先保留已部署单位并归还溢出装备。
- 背包棱晶、强化和冷却宝石兑现同一层邻接规则，无宝石循环放大；奶酪/毒药分别计时并保留余数，药剂达到低生命阈值才触发，炼金师两次独立完整剂量。攻速不增加毒伤，毒伤不反射武器荆棘；面板明确“理论武器伤害/秒”而非伪称实测 DPS。
- 进一步发现敌人旧模板的宝石、奶酪和灵药只是展示，战斗另送隐藏的风格数值。现改为合法装备布局，调用玩家同一 `buildStats`；早期对手也带实际可见武器，不偷偷塞匕首。预览与开战列表一致，并明示赛程基础体质、护盾、武器倍率以及不享受玩家职业/专精。5 项新增同源检查覆盖每轮合法占格、同解析器、宝石/周期、药剂及毒素/荆棘；双端页面检查首轮真实武器和开战前后预览一致。

另做了固定种子、正常购买资源的贪心策略数值诊断（不计入上述 CI 用例数量）：背包 180 个赛季中赤刃 59/60、巡林 60/60、药剂师 60/60 夺冠；自走棋 120 个赛季中商人 30/40、先锋 21/40、先知 31/40 夺冠，未发现推进卡死。这是一次策略诊断，不是最优玩家或真人测评。**背包仍偏容易，长期难度和构筑风险收益没有宣称已经平衡**；本轮先修展示与执行不一致，不盲加血量来制造难度，保留原评级。

截图/JSON 在忽略目录 `output/browser-refresh/` 与 `output/echo-campaign/`，CI 同样执行并保留 artifact。两项工作流的 Actions 固定到已核对的官方 Node 24 运行时版本，运行环境固定 Ubuntu 24.04；游戏测试 Node 22 不变。

仍未覆盖真实手机、Safari/Firefox、低端硬件和长时间前台性能；没有新增异地联机、云存档或 Steam 集成。本次按技能尝试 Tabbit 后台目标创建，任务级 CDP 分派失败；诊断后结束空任务，使用仓库已有独立 headless 测试，不把失败操作记为试玩。射击原型仍在本地，不包含在本次发布和上述 157 项中。研究与设计见 [重启灯塔 SDD](echo-campaign-sdd.md)。

## 可复现检查

```powershell
node --test scripts/test-existing-game-fixes.mjs scripts/test-factory-sandbox.mjs scripts/test-echo-expedition.mjs scripts/test-echo-campaign.mjs scripts/test-echo-compatibility.mjs
node scripts/sync-game-catalog.mjs --check
```

后台浏览器测试使用 `promo-video` 中已有的 Playwright 1.61.1。测试环境可安装依赖与 Chromium；Windows 有 Edge 时优先用 Edge，找不到则用 Playwright Chromium。不打开用户的前台浏览器。

```powershell
node scripts/check-browser-refresh.mjs --echo
node scripts/check-echo-campaign.mjs
node promo-video/scripts/check-tiny-factory-contracts.mjs
```

## 2026-10-04 · 首批本地实际结果（历史记录）

环境：Windows、Node v24.18.0、后台 Edge；桌面 1440×950、手机布局 390×844 / 触屏。下列全部是本次实际执行的结果。

- 发布范围的纯规则测试 **91/91 通过**：旧作缺陷 34、自由工区 24、回声禁区 33。测试提取正式 HTML 中的函数执行，未另写一个测试专用游戏规则；部分旧作规则测试屏蔽绘制，因此不作为 UI 证据。
- `check-browser-refresh --echo` **16/16 页面练习通过**，脚本/控制台错误 0、横向溢出 0。包括四款旧作和目录的双端操作，以及回声禁区的搜刮—存档恢复—撤离、核心区真实移动—画布选敌—EMP 取消范围攻击—暂停续局、存储拒绝后三条双端循环。
- 老合同专项：**12/12 正式参考蓝图三星**，66 个固定设备/障碍、164 格参考路线；桌面真实铺带与逐拍运行完成结算，手机旋转/铺带/撤销正常。这里使用程序加载参考蓝图，不宣称人工独立解出十二关。
- 目录/评级：124 个根目录游戏全部分类一致，115 活跃、9 历史废案。开发测试版不混入计数。HTTP 双端过滤/搜索通过，本地目录的真实点击进入本地 HTML，通过。
- 自由工区：正常起始资金、真实拆建、卖货、研究与供料可推进至电路、扩建、引擎、无人机；不注入资金/原料。每种加工设备执行正式配方两次。修复的分流器在一侧满仓时可以向空闲出口供料，避免煤路与铜路互相拖死。
- 回声禁区：300 张生成地图验证地面连通、出口与箱子可达、守卫不重叠；80 次近端取物返回完成。另有三区各 24 次委托/远端策略和 24 次实际满载远端策略完成，无瞬移或无敌。**这些策略读取完整地图，不是普通玩家难度或乐趣证据**。
- 随机压力：回声禁区 72 次行动、16,414 次决策、2,089 次敌方回合，维持 AP、载重、生命、警报、占格与结算约束；存档由同规则命令回放恢复，重复撤离不得再次领奖。
- 本地未发布射击原型另有 20 项规则回归通过（与发布测试合计 111），但不能据此称其竞技品质达标。

截图和 `browser-results.json` 在本地忽略目录 `output/browser-refresh/`，旧合同截图在 `output/tiny-factory-contracts/`；CI 执行后另存为 Actions artifact。截图已复核桌面/手机地图与控制位置、范围攻击、工区检查器和移动接敌，而非只检查标题页面。

## 已修复的关键体验问题

- 手机回声禁区的方向键原先位于长记录之后，来回滚动影响行动。现在移动同一组按钮到地图下，方向键至少 44px，地图、方向键和结束回合可同时留在 844px 视口；切回桌面再恢复原侧栏位置，不复制状态或事件处理器。
- 深区守卫不只增加数值：研究区锁定直线三格，核心区锁定十字区域，受墙体/视线过滤。地图红叉、检查器、伤害与 EMP 都读取同一攻击范围；攻击不会秘密追踪已经移动的玩家。
- 旧自走棋曾表现为全局选目标攻击，站位价值不足。现有接敌寻路与射程规则已用不同阵型、碰撞占格和真实画面检查，不再让远处近战隔空打最低血单位。
- 坏档、重复结算、战斗中改构筑和存储拒绝均有针对性回归，避免“菜单能打开就算验收”。
- 复核还修复自走棋在低生命时可选致命生命代价强化、导入继承对象属性名导致无效装备，以及两款构筑游戏在剪贴板拒绝时“复制”无反应的问题。自动复制失败会选中存档并给出手动复制提示，双端真实按钮测试覆盖该退路。
- 背包合成过去把旋转后数组的第一个格子当作左上锚点，90°/180° 装备合成后会挪位。先用正式规则复现失败，再改为规范化的最小格锚点，四个旋转方向均验证合成保持原锚点。
- 同一合成流程改为先校验输出空间，再一次性替换两件材料；空间不足不会消耗材料、抹掉强化等级或改变排列。原有放置规则支持同时忽略两件即将消耗的材料，不复制另一套几何逻辑；同名强化上限也与存档校验一致。

1. 首批回声禁区的短线取物容易安全重复；10 月 5 日追加目标链和敌人角色，但风险收益仍需要真实玩家反馈。自动寻路全部成功只说明循环可达；不据此升档。保持测试版标签。

3. 本批无新增异地联机、云存档、成就服务、Steam SDK、商业美术包或商标素材。开发新作不能冒充大型 CS 或商业正式版。
4. 浏览器本地存储可能因换路径、清理、隐私策略消失，迁移前导出档案；存档结构/校验用于损坏检测，不是联网防作弊。
5. 按技能先尝试 Tabbit 后台页面测试，其任务级 CDP 创建目标失败，诊断/结束任务后改用已有项目的独立 headless 回归；没有把失败的 Tabbit 操作记作已完成试玩。
