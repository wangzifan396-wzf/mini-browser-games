# 脉冲音乐室：自由编曲升级 SDD

日期：2026-10-23。基线：`22117f3`。范围：一款旧作的创作循环、声音与保存；不新增正式游戏，不提高评级，不改星团大作战或已冻结作品。

## 为什么做这次更新

旧音乐室虽然能播放，但旋律音高绑定格子、作品槽只保存力度网格，BPM 和静音没有保留；节拍由界面定时器触发，卡顿会直接进入演奏。坏存档的分数索引可使巡演崩溃。重复提交或载入槽位清零编辑次数，也不能代表真正的创作质量。

目标是让玩家完成“动机 → 复制变奏 → 段落排序 → 完整试听 → 带走作品”，而不是增加阈值委托。原十二场巡演作为可选练习保留，旧 `PULSE2` 与浏览器档案兼容。

## 玩法与界面

- 默认进入自由创作，四个可命名乐段，每段六轨十六步；轻拍、正拍、重音与旋律音级分离。底鼓、军鼓、踩镲、低音、和弦、主奏仍然熟悉。
- 四种合成音色创作模式直接开放；调性、大小调、BPM、Swing、逐轨音量、静音与独奏都有实际声音效果。
- 用乐段引用和重复次数编排歌曲，可增删、前后移动；复制乐段深拷贝，不连带修改原段。保守、确定性的变奏只影响当前段，可撤销。
- 点击音符可以改力度；选中音符后可改音级。格子有可读名称，键盘方向键可导航；触屏地图自身横向滚动，页面不横向溢出。
- 关键编辑可撤销/重做；清空、新建、导入和覆盖已有乐段需可恢复或确认。试听使用启动时快照，编辑后停止并提示重新试听，避免导出与试听版本混淆。

## 数据与音频边界

单文件 HTML 仍可直接双击运行，无联网、麦克风、采样资源或第三方运行时。开发用核心源文件通过同步脚本嵌入 HTML；CI 校验一致性，不能维护第二套运行规则。

项目记录四段的力度与音级、编排、调速、音色、调性、音轨和音量。`PULSESONG1` 校验码用于发现损坏，不是加密；本地工程导入先严格验证再替换，失败不改变当前作品。旧 PULSE2 仅包含三个旧网格，迁移为 A–C；无法恢复原来没有保存的 BPM，明确采用 112。

一份纯事件编译器负责段落、音高、Mute/Solo 与 Swing。实时播放和 WAV 渲染复用事件表及合成器。实时以 `AudioContext.currentTime` 计时，约 25ms 唤醒、提前 100ms 安排；画面跟随音频时钟。Swing 保持成对细分总时长，停止清理已安排声音，严重落后或切到后台停止，不补发过期音符。

歌曲最多 16 个编排条目、32 小节且不超过 180 秒。WAV 用 OfflineAudioContext 单声道渲染并编码 PCM16，44100Hz，有限尾音；导出快照、一次一份，处理内存/浏览器不支持错误，检查非有限样本和峰值，必要时整体衰减防削波。不声称网页音量百分比等同安全声压，不把音乐参数验收当作乐曲好听的证明。

## 实施与验收

1. 先确认旧模式实际缺陷与兼容边界；建立纯项目/事件核心和共享合成器。
2. 实现完整创作界面、原子编辑与保存，再修复旧模式坏档、作品切换及播放清理。
3. 纯测试：形状与边界、Swing 成对/整曲时长、音高/静音/独奏、深拷贝、种子变奏、档案往返与旧档迁移、PCM 头/长度/峰值。
4. 后台浏览器：桌面与390×844真实编辑、编排、撤销、导出/导入/刷新、坏档不覆盖；实际离线音频不为全零，播放与停止、后台暂停、音符调度、WAV下载可验证。没有音箱/耳机人工聆听不称“音质已验收”。
5. 旧巡演兼容、原合集回归、计数与文档一致性。更新 README、目录、审计、日志和 SDD/QA；不自动升 S。
6. 修复上一批 CI 依赖安装停滞风险：隔离 Playwright 运行时，不再安装整个视频工程和区域镜像锁文件；分开安装步骤并限定超时。实际日志与推断原因分开记录。
7. 限定文件提交并推送，验证 CI、Pages 与线上 HTML 对应当前源码；保留工作区其他未提交内容。

## 参考与取舍

[Ableton 的歌曲结构教学](https://learningmusic.ableton.com/song-structure/song-structure.html)支持从短型乐段到段落编排的创作路径；借鉴概念而非其 UI、声音或曲目。[web.dev 音频调度](https://web.dev/articles/audio-scheduling)与 [MDN 音序器](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Advanced_techniques)说明音频时钟与界面时钟的不同职责。[OfflineAudioContext 渲染](https://developer.mozilla.org/en-US/docs/Web/API/OfflineAudioContext/startRendering)只产生音频缓冲，WAV 编码与峰值处理必须由本作完成。

本轮不加音频采样、插件链、在线社区、云端账号或付费素材；有限段落的完整创作闭环优先。浏览器调度仍不是专业 DAW 的延迟保证；手机真机、长时间聆听与主观音乐性另列未验证项。
