# 回声禁区 · 重启灯塔 SDD

日期：2026-10-05。状态：已实现并完成列明的自动化验收，真实玩家体验继续收集。承接上一批[设计](browser-games-refresh-sdd.md)，星团大作战保持暂停，不改其游戏或封装。

## 目标与取舍

用户允许大型新作，但质量优先于数量。当前射击原型的机器人、地图、战术道具与演出不足，不以“能开枪”作为 CS 类成品验收。先集中深化已经有可玩闭环的《回声禁区》，不新复制关卡模板，不增加正式目录数量或擅自升级评级。

短线取物能反复安全赚钱，但不足以支撑长期游玩。本次增加一个可选、能结束的“重启灯塔”行动链：玩家必须在现场完成不同操作，并带着证明撤离；基地的钱不能直接购买任务通关。自由搜刮保留，初次玩家不被强制锁进战役。

## 玩法契约

| 决策 | 应产生的真实变化 | 必须避免 |
| --- | --- | --- |
| 侦测中继 | 访问生成的现场节点、取得行动证明 | 改名称但仍只收集相同价值物资 |
| 破解档案 | 支付现场行动成本，处理暴露与撤退路线 | 远程点击菜单直接通关 |
| 改接电源 | 改变区域的现场危险或行动条件 | 只有更高敌人血量 |
| 守住广播 | 在有预告的威胁下持续完成传输，再撤离 | 点击一次终端就自动结算胜利 |
| 敌人角色 | 不同射界、移动或防御；地图与检查器能读懂 | 看起来不同但执行同一攻击 |
| 长期进度 | 完成后仍须撤离；首通奖励只支付一次 | 失败保留未带回证明、重复领首通奖励 |

任务依赖形成目标关系，不做固定六关/十二关三星。地点随种子生成，行动方式与路径仍由玩家选择。重复行动允许练习，但降低重复的专项奖金；普通货物回收不人为归零。保留免费出发、失败不删除基地研究的退路。

## 规则与兼容

- 浏览器与测试运行同一个 HTML 规则内核；不写一份仅供测试必胜的游戏。
- 原有自由搜刮与 v1 行动回放必须继续有效。战役新规则用明确标记区分，不让新敌人规则改变老档的历史操作结果。
- 保留已经发布的 `905d0f4` 引擎生成的 15 份历史存档及完整状态摘要；新版回放必须与历史地图、RNG、守卫、生命、背包及消息逐一一致。不能用新版重新生成“旧档”掩盖兼容问题。
- 任务定义与前置检查共用；不可从伪造任务名、负数 AP 或未知交互获得进度。
- 同种子、装备、起始基地、任务与操作应可复盘。保存进行中行动时记录命令，恢复时重新执行；不信任导入的生命、地图或直接任务结算。
- 本地 JSON 存档不是防作弊服务器。有效存档迁移、错误输入不覆盖当前状态、存储禁用时手动备份都需保留。
- 移动、敌人预告与实际伤害共用范围数据；新任务按钮与触屏布局调用相同事件处理器，不复制第二份手机状态。

## 同批旧作修复

《符文自走棋》检查攻速是否真正改变动作频率、持续加速是否有合理上限、导入的对手预览是否有重叠占格。《背包角斗场》检查棱晶、冷却宝石、强化等级、药剂时机与职业特性是否兑现说明；静态邻接只解析一层，不允许宝石相互循环无限放大。敌方预览装备也需通过同一物品解析器，赛程体质/倍率明示，不另送不可见风格效果。修复先用同源数值复现，再扩充测试。固定策略显示背包赛程仍偏易，长期数值平衡保留为下一轮真人反馈门槛，不因技术回归全绿宣称完成。

## 验收与发布

1. 任务生成：节点可达、不与守卫重叠；任务链从零进度可完成，失败保留基地而不保留当局证明。
2. 同源边界：AP、交互距离、墙体、敌人角色、实际广播计时、首次/重复奖励、依赖、结算一次性、保存回放与旧档迁移。
3. 后台操作：桌面与手机布局用真实按钮完成任务交互、搜刮、撤离、返回基地和恢复；明确哪些策略读取完整地图，不当成人类难度证明。
4. 可读性：现场目标、敌人类型、红叉、操作成本、封锁与广播进度可辨识；地图与常用移动/结束回合同时可操作。
5. 回归：旧游戏、旧工厂合同、离线目录及评级一致；保留未提交的用户文章、宣传片、展柜游戏改动。
6. 发布：更新 README、开发说明、实际 QA 与 CI；只提交本次明确文件，确认 GitHub Actions 与线上版本。未达质量门槛仍明示测试版，不凭测试数量宣称商业品质。

不占用用户前台做长测。当前无异地联机、第三方资源或付费基础设施；真实设备、长时渲染性能与主观乐趣评审的未覆盖部分据实记录。
